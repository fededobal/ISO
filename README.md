### Scripts de la práctica 3

Un script por ejercicio (`N.sh`), entre ellos:

- [12a.sh](2025/Práctica/Práctica%203%20-%20Shell%20scripting/Scripts/12a.sh) a [12c.sh](2025/Práctica/Práctica%203%20-%20Shell%20scripting/Scripts/12c.sh): operaciones aritméticas con números leídos o pasados por parámetro.
- [20.sh](2025/Práctica/Práctica%203%20-%20Shell%20scripting/Scripts/20.sh): pila implementada con un arreglo (push, pop y largo).
- [26.sh](2025/Práctica/Práctica%203%20-%20Shell%20scripting/Scripts/26.sh): manejo de un arreglo con funciones para agregar y eliminar elementos.
- [29/29.sh](2025/Práctica/Práctica%203%20-%20Shell%20scripting/Scripts/29/29.sh): mueve archivos a `/home/bin` y cuenta cuántos movió.
- [30/Bingo.sh](2025/Práctica/Práctica%203%20-%20Shell%20scripting/Scripts/30/Bingo.sh) y [30/Set.sh](2025/Práctica/Práctica%203%20-%20Shell%20scripting/Scripts/30/Set.sh): juego de bingo y estructura de conjunto.
- [menu.sh](2025/Práctica/Práctica%203%20-%20Shell%20scripting/Scripts/menu.sh): menú que ejecuta otros scripts.
